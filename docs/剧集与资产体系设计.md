# 剧集 / 资产 / 剧本 三件套落地设计

> 目标：把「项目 → 集 → 剧本 / 资产 / 视频」，以及「资产分类（角色 / 场景 / 道具）」
> 做进现有 MarkDirector，**不改画布格式、不动 assets/ 语义、老项目打开行为不变**。

## 0. 三条硬约束

| 约束 | 原因 |
|---|---|
| 画布 JSON 格式一行不改 | `markdirectorCanvas` 是节点、连线、工具、技能的公共契约，动了全线崩 |
| `<项目>/assets/` 里 UUID 目录语义不动 | 它是画布节点产物的落地目录，改名会让历史节点全部断链 |
| 读不到 `project.json` 时退回旧行为 | 老项目（如 `1111`、`myProject`）必须能直接打开 |

## 1. 项目档案：`project.json`

新增在**项目根目录**，是唯一的项目级元数据来源。不存在时按旧逻辑推断，不用迁移。

```jsonc
{
  "schema": "markdirector.project/1",
  "name": "一号狂案",
  "style": "3d",                 // 视觉风格 id，见下表
  "aspect": "16:9",              // 16:9 / 9:16 / 1:1
  "createdAt": 1763500000000,
  "episodes": [                  // 集列表（顺序即集号）
    { "id": "01", "title": "她真的是我女儿", "dir": "episodes/01-她真的是我女儿", "status": "draft", "duration": 3, "resolution": "480p" }
  ],
  "assets": {                    // 资产索引：只存引用，实体仍在 assets/
    "characters": [
      { "id": "chr_lingqi", "name": "泠崎", "role": "主角", "refs": ["assets/uuid/1.png"], "prompt": "…", "desc": "…" }
    ],
    "scenes": [ { "id": "scn_yuncheng", "name": "云城城南废弃厂区门口", "refs": [], "prompt": "" } ],
    "props":  []
  }
}
```

视觉风格枚举（先给 6 个，够用且不膨胀）：

| id | 名称 | 适用 |
|---|---|---|
| `3d` | 3D 漫剧 | 游戏引擎级 3D 渲染，半写实角色 |
| `2d` | 2D 日漫 | 赛璐璐上色，二次元 |
| `real` | 写实电影 | 真人质感，胶片调色 |
| `ink` | 水墨古风 | 国风写意 |
| `comic` | 美漫硬核 | 粗描边，强对比 |
| `custom` | 自定义 | 走项目内 `style.md` 自由描述 |

`projectCover.vue` 的封面逻辑保留：优先用 `project.json.cover`，没有就沿用现有「扫 assets/ 第一张图」。

## 2. 分集：子目录，不是新概念

```
<项目>/
  project.json                 ← 项目档案
  画布1.json                   ← 老画布，原样保留（视为「整片画布」）
  assets/                      ← 节点产物，原样保留
  exports/                     ← 成片（exportEpisode 输出）
  episodes/                    ← 新增
    01-她真的是我女儿/
      episode.json             ← 集档案：标题/状态/时长/分辨率
      script.md                ← 原始内容
      rewrite.md               ← AI 改写
      shots.json               ← 分镜（可选）
      画布.json                ← 该集画布，格式与老画布完全一致
```

**关键点：一集就是一个普通画布文件**。所以「进入制作」= 用现有 `openProject` 打开项目、
再用现有 canvasMenu 切到该画布的相对路径。画布组件、节点、技能、工具全都不用改。

兼容性：`episodes/` 不存在 → 项目页显示「未分集」，直接进老画布。

## 3. 资产分类：索引在项目档案，实体不动

素材库从「文件树」升级为「分类网格 + 文件视图」双模式：

- 顶部 tab：**角色 / 场景 / 道具 / 全部文件**
- 角色卡：参考图 + 名称 + 角色类型标签（主角/配角/龙套）+ 生成 / 上传 / 重绘
- 场景卡：参考图 + 名称 + 生成 / 上传 / 重绘
- 「全部文件」保留现有文件树（上传、新建文件夹、重命名、删除完全不变）

资产条目只存 `assets/...` 相对路径，删除资产不动磁盘文件，画布引用也不受影响。

### @ 提及链路

`mentionMenu.vue` 现在是三个 scope：当前画布 / 其他画布 / 全局素材。
新增第四个 **角色**，数据来自 `project.json.assets.characters`：

```
@ + 角色页签 → 选「泠崎」 → 插入 `@泠崎` → Agent 侧解析为项目档案里的参考图路径
```

Agent 侧沿用现有 `resolveCharacterRefs` 的思路：把 `@角色名` 展开成素材清单，
提示词里的 `{{ref N}}` 与清单一一对应。这一步不需要改 Agent 内核，走现有工具即可。

## 4. 剧本改写界面

现在画布里只有「文本节点」，没有独立的剧本工作区。方案：**不新建编辑器**，做一层工作台壳子。

```
┌ 集列表 ┬──── 剧本（复用 document 编辑器）────┬─ AI 操作 ─┐
│ 第1集  │  script.md  |  rewrite.md          │ 拆场景     │
│ 第2集  │  （左右分栏 / 单栏切换）            │ 写分镜     │
│ + 新集 │                                    │ 角色小传   │
└────────┴────────────────────────────────────┴───────────┘
```

- 编辑器直接复用 `panels/document/editorHost.vue`，不重复造轮子
- 「拆场景」= 把 script.md 作为 @ 引用发给 Agent，产出写回 `rewrite.md`
- 「写分镜」= 产出写到 `shots.json`，可再一键生成画布节点

## 5. 首页改版

**项目卡片**（对齐参考稿）：封面 16:9 + 左上状态徽标（待开始/制作中/已完成）+ 右上比例徽标
+ 标题 + 风格标签 + `N 角色 · N 场景 · N 集` + 日期。

**新建项目弹窗**：项目名称 / 视觉风格 / 画面比例 / 保存位置，创建后写 `project.json`。

## 6. 批次与影响面

| 批次 | 内容 | 改动文件 | 风险 |
|---|---|---|---|
| **A** | 项目档案 + 首页卡片 + 新建项目弹窗 | `projectMeta.ts`(新)、`projectCard.vue`、`newProjectDialog.vue`(新)、`home/index.vue` | 低，只碰首页 |
| **B** | 资产分类 + @ 角色 | `assetLibrary.vue`、`assetBrowser.vue`、`mentionMenu.vue` | 中，素材库是画布和首页共用 |
| **C** | 分集 + 项目页 | 新 `pages/project/`、`router` | 中，但只新增路由 |
| **D** | 剧本工作台 | 新 `pages/project/script.vue` | 低，纯新增 |

每批都要 `bun run typecheck` 通过，最后统一 build + 打包，一次性验证。
