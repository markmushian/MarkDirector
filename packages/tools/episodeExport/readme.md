# 成片拼接与角色参考

为 Agent 提供两项能力：

1. `exportEpisode`：把画布上的视频片段按顺序拼成一集成片。
2. `resolveCharacterRefs`：维护角色参考图登记表，把提示词里的 `@角色名` 解析成按顺序排列的素材清单。

## exportEpisode

参数要点：

- `nodeIds`：按数组顺序拼接；省略时自动收集激活画布上的视频节点，按创建顺序排列。
- `paths`：直接给定工作区视频文件，与 `nodeIds` 二选一。
- `outputName`：输出文件名（不含扩展名），默认 `成片-<时间戳>`。
- `mode`：`auto`（默认，规格一致走流拷贝，否则统一规格后拼接）、`copy`、`reencode`。
- `resolution` / `fps`：统一规格时使用，默认取面积最大的片段的分辨率、30 帧。
- `dryRun`：只返回解析出的片段清单，不执行。
- `jobs`：批量任务数组，每项结构与单个任务相同，另有 `retries` 控制失败重试次数。

回执包含输出路径、片段数、总时长、实际使用的模式，以及每个片段的来源与规格。批量任务逐项返回成功或失败原因。

## resolveCharacterRefs

- `list`：查看当前登记表。
- `sync`：从激活画布扫描角色节点，把节点名称与首个图片输出登记进 `.cache/characterRefs.json`；已有条目不会被覆盖。
- `set`：手动登记或更新一个角色（名称、工作区路径、稳定特征描述）。
- `remove`：删除一个角色。
- `resolve`：传入提示词，把其中的 `@角色名` 展开为素材清单；清单第 N 项对应提示词里的 `{{ref N}}`，返回值同时给出改写后的提示词。

登记表存放在工作区 `.cache/characterRefs.json`，属于工作区私有数据，不写入全局素材库。
